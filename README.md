# Analyse d'inférence statistique
Projet d'analyse statistique en Python, étudiant les facteurs liés aux résultats des examens des étudiants.
Jeu de données simulé.

## 📂 Contenu
- `data/student_exam_performance.csv` : jeu de données brut
- `DM_ZHOU_Mengzhe_version20.ipynb` : notebook complet (nettoyage, statistiques descriptives, tests d'hypothèses, graphiques et interprétations)

## 🧰 Dépendances
```bash
pip install pandas seaborn matplotlib scipy
```
## ▶️ Comment lancer

```bash
jupyter lab DM_ZHOU_Mengzhe_version20.ipynb
```

Exécuter les cellules dans l'ordre.

## 📌 Objectif

Étudier l’association entre le genre, la fréquence de révision, la qualité du sommeil et les résultats aux examens, à l’aide de tests statistiques (Chi‑deux, ANOVA, test de Levene).

## ⚠️ Note

Les données sont artificielles. On ne peut pas conclure à une causalité.
